## 주요 변경

- **조각 빠른 편집**: 프롬프트의 `<조각 이름>`을 더블클릭해 큰 편집창에서 바로 수정할 수 있습니다. 조각 이름 인라인 편집과 한글 입력, 편집창 닫기 후 포커스 복귀를 개선했습니다.
- **정밀 인페인트**: 마스크 편집기에 확대·축소, 화면 이동, 1px 브러시·지우개를 추가했습니다. Director에서 이미지를 보며 바로 마스크를 편집할 수 있습니다.
- **Director 도구 패널**: 도구를 용도별로 정리하고, 선택 후 옵션을 확인해 실행하는 방식으로 바꿨습니다. 설정에서 즉시 실행을 켤 수 있습니다.
- **캐릭터 제어**: V5 자유 위치 편집과 가이드, 생성 이미지별 랜덤 캐릭터 선택을 지원합니다. 저장된 좌표를 보존하고 모델 전환 시 위치 컨트롤을 갱신합니다.
- **V5 토큰 계산**: Qwen 3.5 토크나이저를 사용하고 모델별 제한을 표시합니다. 펼친 캐릭터 편집기의 토큰 계산도 모델 전환에 맞춰 갱신됩니다.
- **작업 백업**: 데스크톱에서 이미지 자산을 포함한 `.nais` 백업과 복원을 지원합니다. 복원한 자산은 생성 이미지 저장 위치를 바꿔도 접근할 수 있습니다.
- **연속 생성과 설정**: 배치 전체에서 진행 상태를 표시하며, 생성 간격 랜덤화와 빠른 생성 컨트롤을 지원합니다. 만료된 V5 무료 사용량 표시는 숨깁니다.

## 기존 사용자 데이터

이번 버전은 데이터베이스 스키마 **v18을 유지**합니다. 기존 설정과 작업 데이터를 그대로 사용하며, 백업 복원은 선택한 백업의 작업 데이터로 교체하므로 복원 전에 현재 작업을 백업해 주세요.

## Highlights

- Edit fragment references directly from prompts, with a larger shared editor and improved IME and focus handling.
- Precise inpaint zoom/pan and 1px brushes, plus inline Director mask editing.
- Organized Director tools with explicit actions and optional instant execution.
- V5 freeform character positioning and independent random character selection per queued image.
- Qwen 3.5 token counting and model-specific limits for V5 prompts.
- Portable `.nais` desktop backups including image assets, with stable paths after restoration.
- Reliable batch progress, randomized generation delays, and optional quick generation controls.

Database schema remains **v18**. Existing settings and workspace data are retained. Restoring a workspace backup replaces the corresponding current data; back up your current workspace before restoring.
