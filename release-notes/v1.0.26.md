## 주요 변경

- **V5 업스케일러**: V5 Curated 기반 2배 업스케일과 고정 1 Anlas 비용 표시를 적용했습니다.
- **V5 Auto Text**: 프롬프트와 활성 캐릭터의 인용문을 Auto Text 처리에 포함합니다.
- **다국어 UI**: 한국어·영어·간체 중국어를 지원하며, 언어 전환 시 편집 상태를 유지합니다.
- **기본 조각**: 범용 태그 조각 8종을 제공합니다. 기존 조각은 이름의 대소문자·공백 차이를 고려해 보존합니다.
- **안정성 및 접근성**: 씬 예약의 큐 전달 처리와 버튼·입력 요소의 접근성 라벨을 개선했습니다.
- **개발 환경**: pnpm 기반 설치와 브라우저 개발 모드를 지원합니다. 브라우저 작업 백업에서 API 토큰을 제외했습니다.

## 기존 사용자 데이터

- 첫 실행 시 DB를 **v17에서 v18로 마이그레이션**하며, 그 전에 `backups/pre-migration-v17.db` 스냅샷을 생성합니다.
- 백업에는 WAL에 남아 있는 커밋된 기록도 포함합니다. 백업에 실패하면 마이그레이션을 시작하지 않습니다.
- 기존 데이터가 있는 설치는 설정 테이블이 비어 있어도 신규 설치로 오인하지 않으며, 저장된 언어 선택을 유지합니다.
- **DB v18은 v17까지만 지원하는 구버전 앱에서 열 수 없습니다.** 문제가 발생하면 우선 호환되는 수정 버전을 사용해 주세요. 이전 DB 백업 복원 시에는 업데이트 이후의 변경이 포함되지 않을 수 있습니다.

## Highlights

- V5 Curated 2x upscaling and V5 Auto Text prompt handling.
- Korean, English and Simplified Chinese UI with editor state preserved during language changes.
- Eight default fragment groups with normalized-name collision protection.
- Scene queue handoff and accessibility improvements.
- pnpm and browser development support, with credentials excluded from browser workspace backups.

The first launch upgrades the database to **schema v18** after creating a consistent pre-migration snapshot, including committed WAL data. Older apps supporting only schema v17 cannot open the upgraded database. A database backup does not include changes made after it was created.
